## 部署到网上（拿到网址，任选一种）

### 方式A：Netlify（最简单，拖拽即可）
1. 打开 https://app.netlify.com/drop
2. 把这个文件夹整个拖进网页
3. 自动生成网址，如 https://xxx.netlify.app —— 直接发给别人

### 方式B：GitHub Pages（免费永久）
1. 注册 GitHub，新建仓库（如 li-resume）
2. 把本文件夹所有文件上传到仓库
3. 仓库 Settings → Pages → Source 选 main 分支 / (root) → Save
4. 网址：https://你的用户名.github.io/li-resume/

### 方式C：Vercel
1. 打开 https://vercel.com/new
2. 拖入本文件夹或导入 GitHub 仓库 → Deploy
3. 获得 https://xxx.vercel.app
